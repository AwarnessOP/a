# IP Calculator Telegram Bot

Telegram-бот для расчёта побитового AND.

## Возможности

### Одиночный калькулятор

Ввод:

255 0

Результат:

255
11111111

0
00000000

AND:

11111111
00000000
--------
00000000

Обычный результат:

0

Бинарный результат:

00000000


### Множественный калькулятор

Ввод:

255.0.255
0.255.255

Результат:

Оригинал:

255.0.255
11111111.00000000.11111111

Камуфляж:

0.255.255
00000000.11111111.11111111

AND:

11111111.00000000.11111111
00000000.11111111.11111111
---------------------------
00000000.00000000.11111111

Обычный результат:

0.0.255

Бинарный результат:

00000000.00000000.11111111


## Запуск в VS Code

### 1. Открыть папку

Открой папку проекта в Visual Studio Code.

### 2. Открыть Terminal

В VS Code:

Terminal → New Terminal

### 3. Создать виртуальное окружение

Windows:

python -m venv .venv

### 4. Активировать окружение

Windows PowerShell:

.venv\Scripts\Activate.ps1

Windows CMD:

.venv\Scripts\activate

### 5. Установить библиотеки

pip install -r requirements.txt

### 6. Создать .env

Создай файл:

.env

Внутри:

BOT_TOKEN=твой_токен

### 7. Запустить

python bot.py

Если всё правильно, увидишь:

🤖 Бот запущен!

После этого открой своего Telegram-бота и отправь:

/start
